# RF Mastery — Landing page del curso de radiofrecuencia

Página web de presentación del curso de radiofrecuencia RF Mastery. El sitio incluye información sobre el programa, los módulos del curso, el proyecto final y un aviso legal. Tiene soporte bilingüe español/inglés con detección automática del idioma del navegador.

---

## Tecnologías

- React 18
- Vite 5
- CSS

---

## Cómo correrlo localmente

Necesitás tener Node.js instalado (versión 18 o superior recomendada).

```bash
# instalar dependencias
npm install

# iniciar servidor de desarrollo
npm run dev
```

Abre `http://localhost:5173` en el navegador.

---

## Notas

- El idioma se detecta automáticamente según el navegador y se guarda en `localStorage`.
